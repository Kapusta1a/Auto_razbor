# Админ-панель AUTO_RAZBOR

Панель доступна по адресу `/admin.html` на домене backend-сервиса (Render), а не на статическом GitHub Pages.

## Что умеет

- Добавлять и удалять марки, модели и поколения.
- Редактировать названия, страны, коды поколений, годы и рынки.
- Добавлять ссылки на фото, характеристики и премиум-разбор поколения через структурированные JSON-поля.
- Проверять уникальность ID и базовую структуру каталога перед сохранением.
- Сохранять каталог через закрытый серверный API.

## Настройка доступа

В настройках Render задать:
- `ADMIN_PASSWORD` — длинный уникальный пароль администратора.
- `ADMIN_SESSION_SECRET` — случайная секретная строка (минимум 32 символа; в Blueprint генерируется автоматически).

Не помещать реальные пароли и секреты в GitHub или переписку. Вход создаёт подписанную сервером сессию в HttpOnly cookie с SameSite=Strict и сроком 8 часов. Есть ограничение частоты неудачных попыток входа.

## Важное ограничение хранения

По умолчанию каталог записывается в `data/catalog.seed.json` внутри файловой системы сервиса. На бесплатном/эфемерном хранилище Render изменения могут пропасть при перезапуске, повторном развёртывании или пересоздании сервиса. Перед реальным использованием админки необходимо подключить постоянный диск и задать `CATALOG_FILE` на путь внутри точки монтирования (например, `/var/data/catalog.seed.json`). Если файл на новом диске ещё не существует, backend автоматически скопирует в него стартовый `data/catalog.seed.json` при первом чтении. Постоянные диски Render доступны только платным сервисам; проверьте стоимость и подтвердите платный план до подключения.

GitHub Pages остаётся хостингом Mini App, но после создания Render-сервиса в `public/config.js` нужно указать его публичный URL в `window.AUTO_RAZBOR_API_BASE`. Сервер разрешает API-запросы с `https://kapusta1a.github.io` через `CORS_ALLOWED_ORIGINS`, поэтому Mini App сможет читать живой `/api/catalog` и проверять Telegram `initData` на backend, не меняя адрес Mini App в действующем боте. Пока URL не задан, приложение использует статическую резервную копию `catalog.json`. Текущий webhook и настройки бота не меняются.

## Фото и контент

Пока панель принимает URL фотографий и метаданные атрибуции, а не загружает файлы на сервер. Добавляйте только изображения, которые разрешено использовать, с автором, источником и лицензией. Технические характеристики и платные рекомендации публикуйте только после проверки по конкретному рынку, мотору и году.
