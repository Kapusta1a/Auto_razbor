# AUTO_RAZBOR

Мировая автомобильная энциклопедия и Telegram Mini App.

## Структура каталога

Иерархия данных: **марка → модель → поколение → модификация**.

- `data/catalog.seed.json` — небольшой стартовый набор для проверки структуры.
- Данные в seed-файле не являются полным мировым каталогом и требуют дальнейшего наполнения и проверки по рынкам/годам выпуска.

## План развития

1. Утвердить схему каталога и идентификаторы марок/моделей/поколений.
2. Подключить проверяемые источники данных и импорт с указанием источника и даты обновления.
3. Добавить региональные названия, годы выпуска, кузова, двигатели и комплектации.
4. Подключить каталог к интерфейсу Telegram Mini App.
5. Реализовать серверную авторизацию Telegram и подписку AUTO_RAZBOR PRO через Telegram Stars.

## Принципы данных

- Не смешивать поколения и рестайлинги.
- Указывать рынок/регион, если годы или названия отличаются.
- Не придумывать технические характеристики: неизвестные поля оставлять пустыми.
- Для каждого импортированного набора хранить источник и дату проверки.
