# Подключение AUTO_RAZBOR к Telegram

## Что уже реализовано в проекте
- Веб-интерфейс Mini App: поиск марок, список моделей и поколений.
- API каталога: `GET /api/catalog`.
- Проверка подписи `Telegram.WebApp.initData` на сервере: `POST /api/telegram/auth`.
- Webhook для команд `/start` и `/help`.
- При старте сервера настройка кнопки меню бота через `setChatMenuButton` и webhook через `setWebhook`, если заданы переменные окружения.

## Развёртывание
Нужен публичный HTTPS-хостинг с поддержкой Node.js 20+ (например, Render, Railway или VPS).
1. Подключить GitHub-репозиторий `Kapusta1a/Auto_razbor` к хостингу.
2. Команда запуска: `npm start`; Node.js 20+.
3. Добавить переменные окружения из `.env.example` в панели хостинга.
4. `WEBAPP_URL` — корневой HTTPS URL приложения.
5. `TELEGRAM_WEBHOOK_URL` — тот же домен + `/webhook`.
6. `TELEGRAM_WEBHOOK_SECRET` — случайная строка 32+ символа (не публиковать).
7. `BOT_TOKEN` — токен из BotFather; вводить только в секреты хостинга, не в GitHub и не в переписку.
8. После деплоя проверить `https://ВАШ-ДОМЕН/health`.

При запуске сервер установит webhook и кнопку меню, если все нужные переменные заданы. Если бот уже использует webhook для другого сервиса, не переключайте его до проверки текущей конфигурации: у Telegram у бота может быть только один активный webhook.

## Настройка через BotFather вручную
Если не используете автоматический `setChatMenuButton`, откройте @BotFather → выберите @AutoRazbor_Pro_Bot → Bot Settings → Menu Button → Configure menu button и укажите URL Mini App.

## Безопасность и ограничения
- Никогда не отправлять BOT_TOKEN в чат, коммит или клиентский JavaScript.
- Сервер проверяет HMAC подпись и свежесть initData; данные из initDataUnsafe не считаются доверенными.
- Для production добавьте базу данных, лимиты запросов, журналирование и резервное копирование.
- PRO-подписка и платежи Telegram Stars пока не реализованы. Для цифровых услуг Telegram требует Stars (XTR), обработку pre_checkout_query и successful_payment, а также хранение charge ID.
- Текущий seed-каталог демонстрационный и не является полным мировым справочником. Технические характеристики, ресурсы и типовые неисправности нельзя автоматически считать подтверждёнными.
